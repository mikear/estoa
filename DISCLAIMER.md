# Disclaimer

Estoa is a defensive research tool for authorized security professionals. Use it
only on data and systems you own or have explicit permission to investigate.

## Authorized use

- The application does not perform scanning, exploitation, or intrusion.
- Connectors query public or commercial APIs under their own terms of service.
  You are responsible for the API keys you configure and for the queries you run.
- Some data sources may return personal or sensitive information. Handle it
  according to the laws that apply to you (for example, data protection and
  privacy regulations).

## No affiliation

Estoa is an independent project. It is not affiliated with, endorsed by, or
sponsored by MITRE, VirusTotal, Shodan, urlscan.io, URLQuery, or any other data
source it can query.

## Accuracy

Threat intelligence data changes constantly. The risk score is heuristic triage,
not a verdict, and the ATT&CK bundle is a curated subset of the Enterprise
matrix. Always verify findings against the original source before acting on
them.
