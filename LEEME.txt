================================================================
  ESTOA THREAT INTELLIGENCE PLATFORM v1.0.0
================================================================

Plataforma de escritorio para inteligencia de amenazas, caza de
amenazas, investigación de ciberseguridad, análisis de filtraciones,
enriquecimiento de IOCs y análisis de vínculos.

DESCARGA
  https://github.com/mikear/estoa/releases/latest

  Windows x64 ..... Estoa-windows-x64.exe
                    Estoa-windows-x64-portable.zip
  Linux x64 ....... estoa-linux-x64.deb
                    estoa-linux-x64-portable.tar.gz
  macOS Intel ..... Estoa-macos-x64.dmg
                    Estoa-macos-x64-portable.zip

  Los paquetes incluyen su propio runtime: no hace falta instalar Java.
  La v1 no está firmada; SmartScreen o Gatekeeper pueden pedir
  confirmación. Apple Silicon funciona mediante Rosetta.

REQUISITOS
  - Windows 10/11 x64, Linux x64 con GTK3 o macOS 12+ Intel
  - 4 GB de RAM y 200 MB de disco libre
  - Internet opcional (enriquecimiento y avisos de actualización)

ARRANQUE RÁPIDO
  Instala la app o extrae el portable y ábrela.
  Para cargar el caso de demostración:

    Estoa --demo

  Otras opciones:

    Estoa --version              muestra la versión y sale
    Estoa --no-update-check      omite el aviso de actualizaciones
    Estoa --screenshot DIR       captura 30 pantallas y sale

ACTUALIZACIONES
  Estoa consulta la última release de GitHub como máximo una vez al
  día. Si hay una versión nueva, ofrece abrir la página de descarga;
  nunca descarga ni instala automáticamente. También puedes usar
  Ayuda > Buscar actualizaciones...

QUÉ ENCONTRARÁS
  docs/INSTALACION.md ....... instalación, base de datos y claves API
  docs/ARQUITECTURA.md ...... los 11 módulos y el modelo de datos
  docs/MANUAL-USUARIO.md .... guía completa de uso
  docs/capturas/ ............ capturas reales de la aplicación
  src/ ...................... código fuente completo (Maven)

PRIMEROS PASOS RECOMENDADOS
  1. Arranca con --demo para ver un caso completo de ejemplo.
  2. Añade un observable (dominio o IP) en la barra superior.
  3. Clic derecho sobre el nodo > Transformaciones.
  4. Análisis > Ejecutar correlación.
  5. Informes > Generador de informes.

DATOS Y CLAVES
  La base H2 embebida y las claves API cifradas (AES-256-GCM)
  viven en ~/.orion/. Ninguna clave sale de tu equipo. La app no
  sube datos de casos; solo consulta las fuentes que decidas usar.

COMPILAR DESDE CÓDIGO
  Requiere JDK 21+ y Maven.

    cd src
    mvn test
    mvn clean package -DskipTests -Pwindows   (Windows)
    mvn clean package -DskipTests              (Linux)
    mvn clean package -DskipTests -Pmacos      (macOS Intel)

  Instaladores/portables:

    powershell -File packaging/package.ps1     (Windows)
    bash packaging/package.sh                  (Linux/macOS)
