# Code of Conduct

## Our commitment

We want this project to be a harassment-free space for everyone, regardless of
age, body, gender identity, origin, disability, experience level, education,
socioeconomic status, appearance, race, religion, or sexual identity.

This code is inspired by the Contributor Covenant, version 2.1.

## Expected behavior

- Be respectful and constructive.
- Accept good-faith criticism and focus on what is best for the project.
- Assume good faith and take responsibility for your own mistakes.
- Use inclusive and appropriate language.

## Unacceptable behavior

- Insults, personal attacks, trolling, or discriminatory comments.
- Public or private harassment of any kind.
- Publishing someone else's private information without consent, including
  personal data obtained through the tool.
- Using the project or its channels for illegal activity.

## Scope

These rules apply to issues, pull requests, discussions, and any other
communication channel of this repository.

## Enforcement

Maintainers may edit, remove, or close comments, commits, code, issues, and pull
requests that do not follow this code, and may temporarily or permanently ban
participants.

## Reporting

Report incidents privately to the maintainer through GitHub (@mikear). All
reports are handled confidentially.
